Universal content reader · Agent Skill + CLI + MCP

Turn a URL into source content your AI agent can actually use.

x-reader is a universal content-reading layer for AI agents. It routes X/Twitter, articles, YouTube, Bilibili, podcasts, WeChat, Xiaohongshu, Telegram, RSS and open-web URLs through the right read path, then returns normalized source content for downstream research, summarization and automation.

What the product actually does

Source ingestion first. Evidence awareness second.

Evidence Receipt is a guardrail on top of the reader, not the product definition. The primary job is to retrieve and normalize the source so an agent can use it.

01
Retrieve the source

Platform-specific fetchers and fallbacks turn a user-supplied URL into actual source content.

02
Normalize for agents

Title, URL, source type, body content and relevant metadata become one structured payload.

03
Complete material media

If video or audio matters, x-reader can continue through subtitles, transcripts or local media tooling instead of stopping at page metadata.

Evidence-aware by design

It also tells the agent when the read is incomplete.

This is the trust layer: x-reader does not substitute a search snippet for the source, a post caption for its attached video, or a video description for spoken content.

PASSThe source layers needed for the task were actually read.
PARTIALUseful source content was retrieved, but a material layer is still missing.
FAILThe requested source could not be fetched reliably.
UNKNOWNThe returned material is too ambiguous to prove coverage.

What it is not

Not another summarizer. Not just an AI lie detector.

Summaries and analysis happen after reading. Evidence status is there to keep the source boundary honest. The core product is the reusable reader layer that gets source content into the agent in the first place.
