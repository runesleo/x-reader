The problem

Agents are good at finding something. That is not the same as reading the source.

A search result can look like the article. An X caption can look like the attached video. A YouTube description can look like spoken content. Once those layers blur together, a confident answer can be built on evidence that was never retrieved.

The post can support claims from its text. The unread video cannot. x-reader keeps that boundary visible instead of silently upgrading it to “read.”

Why it exists

Source verification should be a primitive, not a prompt trick.

x-reader does not ask a model to be more careful. It creates a machine-readable evidence contract the model, workflow or researcher can inspect.

01
Read the original layer

Start from the URL the user actually gave you, not a search preview that merely mentions it.

02
Keep missing media missing

If attached video or audio matters but was not consumed, the result stays partial.

03
Return an evidence receipt

Humans and agents get the same explicit boundary: what passed, what did not, and why.

The contract

Four states. No fake completion.

PASSThe requested source layer is actually evidenced as read.
PARTIALUseful material was read, but a material layer is still missing.
FAILThe requested source could not be fetched reliably.
UNKNOWNThe material is too ambiguous to prove coverage.
